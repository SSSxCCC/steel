# 创建项目

当前编辑器使用启动它的Steel应用，不会通过Project菜单创建或编译一个独立的Rust项目。请从仓库自带的示例项目开始。

## 运行接球示例

仓库的`examples/ball`包含本教程游戏的源码和资源。为了让编辑器找到示例的`assets`目录，请从`examples/ball`目录启动：

```
cd examples/ball
cargo run --features steel-engine/editor
```

## 创建新项目

将`examples/empty-project`复制到仓库`examples`目录下的一个新目录，并修改`Cargo.toml`中的package名称。模板里的`steel-engine`路径依赖相对于仓库根目录；若将项目放在仓库外，请调整该路径指向Steel仓库。然后在新项目目录运行`cargo run --features steel-engine/editor`。编辑器使用进程当前工作目录下的`assets`目录存放游戏资源。

编辑器的“Project -> Compile”菜单用于初始化或重新加载应用状态，不会调用Cargo编译Rust源码。修改游戏代码后，需要重新构建并启动应用。
