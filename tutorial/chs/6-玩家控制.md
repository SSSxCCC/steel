# 玩家控制

本章编写球板的控制逻辑。

## Player组件

球板是玩家控制的对象。创建一个组件标记它，并保存移动速度：

```rust
#[derive(Component, Edit, Default)]
struct Player {
    move_speed: f32,
}
```

在`main`中的`SteelApp`构建链注册`Player`：

```rust
    .register_component::<Player>()
```

启用编辑器重新构建并启动应用后，为Board实体添加`Player`，将`move_speed`设为10，然后保存场景。

## 玩家控制系统player_control_system

将球板的`RigidBody2D`类型设为`KinematicVelocityBased`，这样速度由游戏代码控制，不会因重力而下落。游戏客户端通过egui context提供键盘和触屏输入：

```rust
fn player_control_system(
    player: View<Player>,
    mut transform: ViewMut<Transform>,
    rb2d: View<RigidBody2D>,
    mut physics2d_manager: UniqueViewMut<Physics2DManager>,
    egui_ctx: UniqueView<EguiContext>,
) {
    for (player, transform, rb2d) in (&player, &mut transform, &rb2d).iter() {
        if let Some(rb2d) = physics2d_manager.rigid_body_set.get_mut(rb2d.handle()) {
            let mut linvel = Vec2::ZERO;
            egui_ctx.input(|input| {
                if input.key_down(egui::Key::ArrowLeft) {
                    linvel = Vec2::new(-player.move_speed, 0.0);
                } else if input.key_down(egui::Key::ArrowRight) {
                    linvel = Vec2::new(player.move_speed, 0.0);
                }
                if steel::platform::BUILD_TARGET == BuildTarget::Android {
                    if let Some(press_origin) = input.pointer.press_origin() {
                        if press_origin.x < input.screen_rect.center().x {
                            linvel = Vec2::new(-player.move_speed, 0.0);
                        } else {
                            linvel = Vec2::new(player.move_speed, 0.0);
                        }
                    }
                }
            });
            rb2d.set_linvel(linvel.into(), true);

            if transform.position.x > 9.0 {
                transform.position.x = 9.0
            }
            if transform.position.x < -9.0 {
                transform.position.x = -9.0
            }
        }
    }
}
```

将系统注册到`Schedule::Update`，使其在游戏运行时执行：

```rust
    .add_system(Schedule::Update, 0, player_control_system)
```

按住左右方向键时，系统设置球板的水平速度。在Android上，触摸屏幕左半边或右半边可选择移动方向。位置检查确保球板不会离开游戏区域。完整实现可参考[`examples/ball/src/lib.rs`](../../examples/ball/src/lib.rs)。

## 构建Android客户端

Android不支持Steel编辑器，Android构建使用Steel客户端。安装包含SDK和NDK的Android Studio、Java 17、Rust目标平台和cargo-ndk：

```
rustup target add aarch64-linux-android
cargo install cargo-ndk
```

在游戏项目目录（例如`examples/ball`）执行以下命令构建Android原生库：

```
cargo ndk -t arm64-v8a -o target/android/jniLibs build --lib
```

将生成的原生库和游戏的`assets`目录打包进Android应用。Steel目前不包含Gradle应用壳工程，也没有从编辑器菜单安装APK的功能。
