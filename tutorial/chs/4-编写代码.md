# 编写代码

游戏代码属于Rust应用程序，不再通过动态库加载。使用VSCode打开你在上一章创建的项目中的`src/lib.rs`。本教程中的接球游戏代码可参考Steel仓库的`examples/ball/src/lib.rs`。

## 应用入口

`#[steel_main]`属性会生成Steel所需的平台入口。默认情况下，`SteelApp::run()`启动游戏客户端；启用`steel-engine/editor` feature时则启动集成编辑器。

```rust
use steel::{
    app::{Schedule, SteelApp},
    log, steel_main,
};

#[steel_main]
fn main() {
    SteelApp::new()
        .add_system(Schedule::Init, 0, hello_world)
        .run();
}

fn hello_world() {
    log::info!("Hello world!");
}
```

`add_system`依次接收运行阶段、该阶段内的执行顺序和系统函数。在自己的项目根目录运行应用：

```
cargo run --features steel-engine/editor
```

编辑器运行的是与其一起构建的应用。修改Rust代码后，需要停止并重新构建、启动应用；“Project -> Compile”不会编译Rust源码。不启用该feature时，`cargo run`会启动游戏客户端。

## 添加Physics2DPlugin插件

接球游戏使用2D物理引擎。将插件添加到已有的`SteelApp`构建链中：

```rust
use steel::physics2d::Physics2DPlugin;

SteelApp::new()
    .add_plugin(Physics2DPlugin)
    // 在这里注册组件并添加系统。
    .run();
```

插件可以组合游戏模块需要的组件、单例和系统。`Physics2DPlugin`提供本教程所使用的2D物理功能。

后续章节展示的是对现有`SteelApp`构建链和游戏系统的增量修改，不是替换应用入口。完整导入和可运行应用请参考[`examples/ball/src/lib.rs`](../../examples/ball/src/lib.rs)。
